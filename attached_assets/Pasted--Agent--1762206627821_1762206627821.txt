**Преимущества:**
- ✅ Быстро (сегодня закончим)

- ✅ PostgreSQL/Drizzle продолжат работать
- ✅ React Query не нужно переписывать

1. `npm install --save-dev react-snap` (2 мин)
2. Настроить package.json (5 мин)
3. Обновить main.tsx для hydration (10 мин)
